SEATSCAPE | CGV 대구죽전 3관 시제품 (2가지 버전)
================================================

실행:
  1. ZIP 압축을 풉니다.
  2. 폴더의 index.html 파일을 Chrome 또는 Edge로 엽니다.
  3. 2D 또는 3D 버튼을 눌러 체험합니다.

인터넷 연결 없이 사용하도록 HTML/CSS/JS와 사진을 모두 함께 넣었습니다.

버전 A: version-2d/index.html
  - A~C 각 10석, D열 1·2번(휠체어 공간), 9·10번
  - 좌석 34곳을 표시하고 4곳에 실제 촬영 사진 연결
  - 사진 썸네일 / 클릭 / 확대 팝업

버전 B: version-3d/index.html
  - 실제 배치도를 참고하여 만든 간단화 3D 가상 상영관
  - 마우스 드래그로 카메라 회전, 휠로 확대/축소
  - 3D 좌석 번호를 클릭하면 오른쪽에 해당 시야 사진 표시
  - 위에서 보기 / 시점 초기화 기능
  - Three.js나 외부 서버 없이 독립 실행되는 Canvas 3D 렌더링

등록된 좌석별 사진:
  B10: 원본 'B열10번 뷰.jpg'
  C7: 원본 'C열7번뷰.jpg'
  C10: 원본 'C열10번뷰.jpg'
  D10: 원본 '죽전3관 D열10번뷰.jpg'
  그 외: 실제 사진 없음이라고 명시적으로 표시

소스:
  shared/data.js: 좌석/사진 매핑
  shared/viewer.js: 사진 표시 및 클릭 연결 공통 기능
  shared/common.css: 전체 디자인
  version-2d/index.html: 2D 좌석 배치도
  version-3d/index.html: 3D UI
  version-3d/scene.js: 3D 지오메트리/카메라/선택 로직
  assets/: 제공된 이미지에서 변환한 웹 최적화 사본

한계:
  - 3D는 공간 실측 스캔이 아니고 참고 사진/좌석 배치도로 만든 추정 모델입니다.
  - 좌석 시야는 촬영한 사진에 대해서만 제공하며, 미등록 좌석의 모습을 임의 생성하지 않습니다.
  - D1/D2는 배치도의 휠체어 표시를 기준으로 비워 둔 공간으로 표현했습니다.
  - 실제 공개 서비스 전에는 해당 사진의 공개 활용 및 촬영 허가 등 확인이 필요합니다.

새 사진 추가:
  1. 좌석 사진을 webp/jpg로 assets 폴더에 넣습니다.
  2. shared/data.js 의 photo 에 예: 'A5':'../assets/view_A5.webp' 를 추가합니다.
  3. 같은 파일의 sourceName 에 예: 'A5':'A열5번뷰.jpg' 를 추가합니다.
  4. 필요한 경우 헤더의 사진 등록 수 표기를 갱신합니다.
