SEATSCAPE 2D + 3D 통합 시제품 (2026.10)

1. ZIP 파일의 압축을 완전히 풉니다.
2. 폴더 안 index.html 을 Chrome 또는 Edge로 엽니다.
3. 2D 좌석 시야 또는 3D 영화관 둘러보기를 선택합니다.

포함 내용
- 2D 버전: 기존 좌석 클릭 UI 유지
- 3D 버전: 기존 입체적 비스듬한 시점 복원, 스크린 쪽으로 향한 리클라이너, 계단형 바닥과 통로, 뒤쪽 출입구 표현, 사람 없는 가상 극장
- 실제 시야가 연결된 좌석 B10, C7, C10, D10
- 사진이 없는 좌석은 '사진 준비 중'을 표시합니다.
- 메인 페이지 3D 소개 카드에는 사람 없는 영화관 커버 이미지 사용
- original_jpg/: 사용자가 제공한 원본 6개 JPG 파일. 수정 없이 그대로 보관

제약사항
- 3D 공간은 정밀 실측 모델이 아니라 사진과 배치도를 토대로 한 상호작용형 시제품입니다.
- 좌석별 실제 시야는 기존 제공된 사진이 있는 네 좌석만 표시합니다.
- 웹사이트는 HTML/CSS/JS로 구성되어 추후 수정할 수 있습니다.
